# 使用指南

## 准备环境

ParcelCrop 4x6 面向 Windows x64，要求 .NET Framework 4.8。便携包完整解压后运行 `ParcelCrop.exe`，不要在 ZIP 内直接运行。处理过程需要源 PDF 所在目录的写入权限和可用的系统临时空间。

### 配置 PDF 渲染器

应用需要 MuPDF 的命令行工具 `mutool.exe`。公开便携包只提供 ParcelCrop 本身，不包含渲染器。

1. 从 [MuPDF 官方 Releases](https://mupdf.com/releases)或其 [Artifex 官方下载仓库](https://github.com/ArtifexSoftware/mupdf-downloads/releases)选择 Windows 发行版。
2. 解压并保留该发行版的许可、版权及第三方声明材料。
3. 将 `mutool.exe` 放在 `ParcelCrop.exe` 旁；也可以把环境变量 `PARCELCROP_MUTOOL` 设置为已有 `mutool.exe` 的完整路径，再重新启动 ParcelCrop。

临时使用指定渲染器，可从便携包所在目录打开 PowerShell：

```powershell
$env:PARCELCROP_MUTOOL = 'C:\Tools\MuPDF\mutool.exe'
& $env:PARCELCROP_MUTOOL -v
./ParcelCrop.exe
```

这里的路径是示例，替换为实际文件路径。该环境变量只影响当前终端及由其启动的程序。渲染器版本和兼容性以实际运行与对应版本验证记录为准；不要把旧便携包的二进制版本声明当作对任意新版的验证。

## 裁切与导出

1. 点击 **Browse files** 或 **Add files**，可多选；也可把 PDF 拖入应用。每个文件必须只有一页，重复加入同一路径不会创建重复任务。
2. 选择右侧队列中的文件，等待 **Ready**。左侧 **CROP** 显示整页与自动检测框，右侧 **OUTPUT** 显示最终布局预览。
3. 拖动框内部改变位置；拖动四角等比缩放。框保持初始检测比例，不能任意拉伸宽高。**Detect** 恢复自动检测范围，**Rotate** 每次顺时针旋转输出 90°。初始横向检测区域会自动选择竖向输出方向，请仍检查文字朝向。
4. 逐个检查任务。应用没有“同一裁切框应用到所有文件”的设置，各文件保留自己的裁切范围和旋转。
5. 默认保留 PDF。仅在确实需要时勾选 **Move PDF to Recycle Bin after successful export**；该选择在启动本次批处理时确定。
6. 点击 **Process all**。每个 JPG 保存为源 PDF 的同目录同主文件名，例如 `order.pdf` → `order.jpg`。
7. 点击 **Open folder**，定位已导出的 JPG；尚未完成时定位源 PDF。

**Clear** 和移除按钮只清理队列，不删除源文件。处理中可选择 **Stop after current**；正在保存的输出会完成，后续任务停止。错误详情可在当前任务说明或悬停提示中查看；修复原因后使用 **Retry unfinished**，或将文件移除后重新加入。

## 比例、尺寸与打印

输出固定为竖向 1600×2400 px、400 DPI，即 4×6 英寸（101.6×152.4 mm），宽高比 2:3。裁切内容保持比例、居中放入白色画布，四边至少 24 px；某些比例的内容会有更大的上下或左右留白。

4×6 英寸不严格等于 100×150 mm，二者只有宽高比相同。打印时根据实际标签纸选择尺寸并检查驱动缩放，避免误把“适合页面”当作原始尺寸。先打印一张并检查文字、完整条码及条码周围留白，再打印整批。输出 JPG 使用有损压缩；应用不会证明每种打印机或扫描器都可识读。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示缺少 `mutool.exe` | 检查同目录文件或 `PARCELCROP_MUTOOL` 完整路径，重新启动应用 |
| `Multiple pages found` | 先拆成单页 PDF；本工具不会自动忽略额外页面 |
| `Blank page` / `No label found` | 检查源文件是否有可见内容；浅色背景、特殊扫描可能影响检测 |
| 输出有空白或选错区域 | 检查左侧框、移动或调整其大小，再观察右侧预览；不是所有模板都能自动正确识别 |
| 提示同名 JPG 已存在 | 移动或重命名已有 JPG 后重试；应用不覆盖它 |
| 提示 PDF 在预览后发生变化 | 从队列移除，再重新添加，以新内容重新预览 |
| 提示 PDF 无法读取 | 确认文件完整，使用可访问且不需要密码的 PDF；本工具不提供密码输入 |
| JPG 保存后原 PDF 还在 | 默认行为；即使勾选回收，回收站不可用或文件占用也会保留 PDF 并提示 |
| 资源管理器没有立即显示 JPG | 先用 **Open folder** 检查实际路径。2.2.0 导出后会发送 Shell 通知；若仍复现，报告 Windows 版本、目录类型、是否同步目录和完整步骤 |
| 批处理慢或超时 | 渲染一次只执行一个任务；每次渲染器调用有超时。先尝试较小或重新导出的 PDF，并记录渲染器版本 |

网络共享、可移动介质或同步目录的通知和回收行为可能与本地固定磁盘不同。请根据具体位置验证，不能把一次本地成功视为所有存储环境均受支持。

## 隐私与临时文件

文档处理在本机执行。预览会创建临时 PDF 副本和 PNG，正常移除任务、清空或退出时释放；异常终止可能留下 `%TEMP%\ParcelCrop` 下的任务目录。关闭应用后再检查残留。报告问题时优先提供合成样例，不公开真实面单。
